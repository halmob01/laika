# Studi grafici originali LAIKA

Tre HTML completi forniti dall'utente e acquisiti con la [PR #12](https://github.com/halmob01/riv-russa/pull/12). Sono conservati senza modifiche, con gli stessi blob Git del caricamento. Sorgenti/prototipi sperimentali del futuro kit SVG: **DA VERIFICARE, normalizzare, gestire e implementare correttamente a livello tecnico. L'accettazione della PR non certifica l'idoneità alla produzione.**

- [Estetiche brutaliste — Fase A](estetiche%20brutaliste%201.html): 21 elementi architettonici/compositivi.
- [Palazzi brutalisti — Fase B](Estetiche%20brutaliste%202.html): 15 edifici/varianti.
- [Studio personaggi](studio%20personaggi.html): pose, varianti, oggetti, folle, ambienti e mezzi.

Dalla radice della repository eseguire `npm run serve`, poi aprire ciascun HTML in una pagina separata, per esempio <http://localhost:4173/prototypes/laika-studi-originali/estetiche%20brutaliste%201.html>. Le UI originali possono richiedere spazio desktop: la conservazione non ne corregge impaginazione o resa. I pulsanti di export appartengono agli studi; non esportano dati runtime già validati.

[Inventario e criteri tecnici](../../docs/LAIKA-STUDI-SPERIMENTALI.md) · [Manifest di integrità e catalogo di authoring](manifest.json). Gli hash si riferiscono ai file caricati su GitHub dall'utente; nessuna verifica diretta degli allegati della chat è dichiarata. Autore/licenza da verificare. Non inserire l'HTML nel DOM del player e non riscrivere i sorgenti per normalizzarli: creare eventuali derivati separati, con confronti visuali.
