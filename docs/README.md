# Documenti

## Ordine di autorità

Quando due documenti dicono cose diverse vale il primo di questa lista; l'altro va corretto nella stessa PR.

1. [laika/DECISIONI.md](laika/DECISIONI.md): le decisioni del docente.
2. `games/laika/canone.json`, letto in [laika/CANONE.md](laika/CANONE.md): atti, unità, numeri, titoli, gioco di ogni unità, stato.
3. Le schede: degli episodi in [laika/atti/](laika/atti/), dei giochi in [laika/giochi/](laika/giochi/).
4. Tutto il resto.

`archivio/` non vale come istruzione: è la storia delle decisioni.
